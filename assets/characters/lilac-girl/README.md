# 棉棉 · 游戏角色素材包

基于用户在本项目中生成的小女孩插画，以 `generate2dsprite` 制作。角色名为“棉棉”，沿用 `lilac-girl` 作为稳定素材 ID。当前美术版本为 `youyou-eyes-v2`：参照悠悠的圆润大眼睛、清晰眼白/深色瞳孔与简洁脸部明暗，七组动作已统一；帽子、服装、身高与原动作保持。

`references/face-style-master.png` 是当前脸型锚点，`youyou-eye-style.png` 是画风参考；`portrait.png` 仅保留最初照片派生插画的来源记录，不代表当前脸型。实际内置 image_gen 编辑提示词保存在各动作的 `prompt-used.txt`，待机母提示词见 `face-style-prompt.txt`。

## 交付范围

- 7 组动作，每组 4 张 256×256 RGBA PNG，共 28 帧。
- 每组一张 2×2 透明合图、一份 4 帧透明 GIF、原始洋红底图、清理图、实际生成提示词和 QC 元数据。
- 一份共享比例配置、角色动作清单、完整检查报告、离线动作预览页及所有帧总览。
- 全部原始美术来自内置 `image_gen`；脚本仅做抠色、切帧、统一缩放、锚点处理与最终资产排版。

| 动作 | 场景 | 帧间隔 |
|---|---|---|
| idle | 等待／准备 | 240 ms |
| run | 溪边前进 | 120 ms |
| jump | 起跳／空中／落地姿势 | 170 ms |
| hover | 萤火虫关卡跟手漂浮 | 180 ms |
| hurt | 受惊／坠落救援姿势 | 190 ms |
| bump | 普通障碍轻微碰撞 | 170 ms |
| celebrate | 准备／成绩页，比耶庆祝 | 190 ms |

## 查看

双击 `preview.html`。可选择动作、暂停、逐帧、半速、左右翻转及深浅背景。全部资源均在本包内，不依赖外网。

`all-actions-preview.png` 按表格顺序从上到下排列，每行从左到右为帧 1–4。GIF 用于快速复查，游戏应使用 PNG，避免 GIF 有限色与单比特透明边缘造成的损失。

## 与游戏的兼容关系

与现有 `assets/characters/character-roster.json` 一致：`<id>/<action>/<action>-1.png` 至 `-4.png`，动作命名、尺寸、帧数及帧间隔与当前游戏匹配。朝向默认向右，庆祝头部可稍向观察者；向左由运行时水平翻转。角色待机可见高度约 175px，与现有悠悠约 176px 接近。

所有动作共享同一 `character-scale-profile.json`：preserve 缩放、256px 格子、feet 对齐、输出原点 `[128,231]`。没有逐帧归一化，也没有按动作改变缩放。跳跃、漂浮与救援的世界位移交给游戏，素材表达屈膝、伸腿和后仰，不应把图片自身当作物理轨迹。

当前状态为 **integrated**。已同步角色名单、HTML 中的 `CHARACTER_DEFINITIONS`、选择卡片及六角色布局，棉棉可在输入准备后的角色选择页选中，贯穿三个玩法、结算和重玩。其他角色、碰撞盒与玩法规则保持不变。

## 质量检查

详见 `qc-report.json`：28 帧 RGBA/尺寸/非空、透明背景、无洋红残留、无源或输出边缘接触、无粘贴裁切；7 组均使用同一缩放与原点。跨动作体量漂移要求 ≤8%。站立动作的体量 CV ≤0.08、原始纵向锚点标准差 ≤0.05；跳跃/漂浮/救援不套用站立姿态的原始 y 门槛。
