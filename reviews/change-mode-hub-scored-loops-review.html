阶段摘要

本阶段关键决策

  • 用户已确认三个入口本质是并列玩法，首次进入全部可选；不再使用顺序关卡与完成解锁
  • 全局只确认输入可用，主 CTA 为“开始游戏”；拳掌、上下跟手、叠云分别在玩法内安全段教学
  • 玩法内部采用温和无限计分：每 20 秒速度 +0.1×、最高 1.6×，3 颗勇气心用完结束本局
  • 排行榜收敛为同设备、同玩法的匿名个人 Top 5，不做账号、昵称、联网公开榜或跨设备同步
  • L1 世界与目标共享 worldSpeed，1200ms 跳跃匹配 1.05s 预告；掉坑有坠落、托回、扣心与短暂无敌

被放弃的方案

  • 不把三个玩法继续包装成必须依次完成的三关
  • 不在玩法大厅之前一次教授三套控制
  • 不做固定时长终点、经典 Flappy 碰撞即死或单次失误重开
  • 不建立儿童公开排名、全球榜或跨玩法总榜

进入下一阶段的条件

  • 方向、架构、功能与原型规格已由用户明确确认并传播到 04B
  • Phase 4B 实现通过专项 QA 后，等待 PM 实际试玩确认手感基线

不需要 PM 审查的执行细节

  • localStorage key、worldX 更新公式、测试 seam 与 Playwright 选择器
  • MediaPipe 连续帧、EMA/死区和 CSS 动画细节
