阶段摘要

本阶段关键决策

  • 用户已确认第三玩法不要继续自创叠云，改用成熟的自动弹跳 + 左右落平台心智
  • L3 正式命名为树梢蹦蹦：角色持续自动弹跳，下降落台立即再弹；到达上方阈值后镜头向上追随，掌心 X 或 ←/→ 只控制横向
  • L2 判定生命周期与视觉生命周期解耦：越过角色后仍继续移动到完整离场
  • 成绩页改为左右双列，在六个目标视口完整展示 Top 5 与全部操作按钮
  • 保持 web-only、本地识别、设备内匿名 Top 5、低挫败和原创素材边界

被放弃的方案

  • 不保留拳掌叠云这一自创主循环
  • 不把赛车躲避作为 L3，因为它与 L2 连续躲避过于同质
  • 不把涂色塞入本轮计分主线；它更适合作为未来无分数、无时限创作模式
  • 不复制 Doodle Jump 的名称、美术、角色、关卡、平台素材或商业表达

进入下一阶段的条件

  • 已满足：用户明确要求成熟玩法心智并授权调整
  • 已满足：01A→04B、试玩/验收、QA 与 Phase 4B Review Console 均已同步
  • 下一步由 PM 实际试玩 L2 完整离场与 L3 连续攀升/镜头追随

不需要 PM 审查的执行细节

  • passedObjects 数组、worldX/worldY 过滤阈值、EMA/死区/限速和测试时间推进
  • CSS 双列压缩参数、Playwright 选择器与本地存储 key
