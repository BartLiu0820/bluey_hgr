阶段摘要

本阶段关键决策

  • 从初始界面到成绩页，儿童常显层只保留一个短标题、一个当前动作短句和一个主 CTA；完整隐私、错误恢复与技术信息保留在家长/折叠/无障碍层
  • 输入准备只确认摄像头或按键可用，主 CTA 为“开始游戏”；三个玩法的操作教学分别位于各自安全段
  • 溪边跳跳、萤火虫躲躲、树梢蹦蹦首次进入即全部可选，不再采用完成上一关后解锁的顺序关卡
  • 三个玩法均进入温和无限计分：每 20 秒速度 +0.1×、最高 1.6×，3 颗勇气心用完结束本局
  • 成绩按玩法保存当前设备个人最好与竖向降序 Top 5；左侧当局单帧只在当前页面内存中短暂存在，本轮不引入账号、昵称、联网榜、画面保存/上传或跨设备同步
  • L1/L2 障碍判定后进入离场队列并继续向左完整离场；普通命中播放双角色新 bump 状态；L3 采用真实世界高度/重力、下降落台再弹、上方阈值镜头追随与掌心 X 横向控制
  • 三关使用低干扰远景/中景分层地图；L1 额外提供可正反向无缝横向循环的地面，障碍、树篱、踏板与安全云均为独立结构物件
  • 玩法大厅预览、玩法出发封面和成绩页复用当前玩法地图；地图外界面统一为暖纸张冒险手册风格；L1 水坑使用独立透明物件且碰撞仍来自运行时几何
  • 输入/大厅与三玩法使用 4 条 18 秒丰富欢快循环 BGM；14 个状态边沿音效覆盖关键反馈，家长总开关、后台/暂停停播与静默降级控制儿童声音环境
  • 顶部完整图片面板收拢唯一分数、距离/高度、阶段和安全内缩进度，去除左侧重复计分；角色脚部贴近道路，顶部指示紧贴安全区上沿
  • 初始背景和按钮替换为统一的手绘探险资产；按钮按紧凑圆形、宽版 CTA、中型操作三档分别生成完整图片并直接作为点击本体，不再嵌入旧文字按钮；成绩页以左右分区在六个目标视口展示当局留念、竖向 Top 5 与操作按钮

被放弃的方案

  • 不保留顺序解锁，也不在玩法大厅上方统一教授三种不同操作
  • 不采用固定 40/45/50 秒到终点的伪无限循环
  • 不采用经典 Flappy 的窄缝、碰撞即死或单次失误反复重开
  • 不保留自创的拳掌叠云，也不复制 Doodle Jump 的品牌、美术、角色或关卡素材
  • 不使用角色台词、语音旁白、警报、爆炸、尖叫、联网流媒体或复杂混音台
  • 不把设备内 Top 5 扩张为儿童账号、昵称、公开或全球排行榜

进入下一阶段的条件

  • 从初始界面走摄像头与按键两条路径，确认新菜单背景/按钮、顶部唯一信息面板和当局留念没有突破儿童文字预算或隐私边界
  • PM 试玩并确认输入准备 → 玩法大厅 → 玩法内教学 → 重复挑战的产品心智成立
  • PM 试玩 L1/L2 碰撞动作与障碍完整离场、L3 连续攀升/镜头追随，确认空间连续性和成熟玩法心智成为基线
  • PM 确认三关地图可区分、L1 长时间循环无明显接缝，且背景不会压过角色和可交互物件
  • PM 确认玩法大厅 → 出发封面 → 运行态 → 成绩页的地图/UI 连贯，且 L1 新水坑清晰可读
  • PM 试听大厅/三玩法 BGM 与关键事件音，确认音量、语义、无惊吓与家长声音开关成为基线
  • Gate confirmed 后进入家长陪同真实 5 岁儿童试玩

不需要 PM 审查的执行细节

  • LevelDefinition 目标毫秒值、测试注入接口与确定性时间推进
  • MediaPipe 模型加载、连续帧稳定、关键点计算与内部事件字段
  • CSS clamp、碰撞体、视差、动画曲线、音频冷却毫秒与 Playwright 选择器

Q-04B-COPY-000 Route hint: L1

是否确认从初始界面到成绩页，孩子只凭图形、角色反馈和一个短提示就能找到下一步？

为什么问

5 岁儿童阅读能力有限；介绍段、步骤清单、技术状态和重复说明会挤占角色与主操作的注意力。

风险与下一步

风险

  • 少文字不能变成无提示：当前动作、实时米数/里程碑、错误恢复和无障碍名称必须继续保留；真实儿童理解仍需陪同试玩确认
  • 自动化不能替代真实 5 岁儿童在家庭环境中的准确率、理解和疲劳验证
  • 生成式背景、地图一致性 UI 与新水坑已完成静态降噪和多视口截图审阅，但真实儿童是否被局部装饰分散注意力仍需陪同试玩观察
  • L1 加速后的跳跃时机、L2 跟手参数与 L3 平台宽度/横移灵敏度仍需根据真实试玩校准
  • 生成音频已完成格式与映射检查，但音量舒适度、循环接缝和儿童惊吓反应仍需人工试听与真实儿童陪同观察
  • 设备内 Top 5 不区分家庭成员；多人档案、清榜入口和跨设备同步不在本轮
  • 本轮 Target Surface 仍是 web-only 笔记本；移动 Web 不在本 Gate 范围

下一步

  • 等待 PM 试玩确认顶部唯一信息面板不会重新造成信息过载，且碰撞动作/离场因果适合 5 岁儿童
  • 等待 PM 确认初始背景/按钮、结果页当局留念/竖向榜单，以及大厅/三玩法新 BGM 与家长声音开关
  • 确认后进行一次家长陪同真实儿童试玩
  • 新问题继续经 Change Router 回到对应 L0–L4
