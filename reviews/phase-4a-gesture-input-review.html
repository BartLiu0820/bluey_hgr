阶段摘要

本阶段关键决策

  • 保持 GI-01–GI-06 六个 screen 与单一 gesture-input-main backbone；GI-03 只练一次拳→掌→拳，首轮后可自愿重复
  • GI-04/GI-06 输出 camera_full 或 keyboard_full，二者都声明 capabilities.poseTransition=true 与 capabilities.handTrackingY=true
  • 关卡交接使用 PoseTransitionEvent 与逐帧 HandTrackingFrame；L2 在 label=None/Unknown 且关键点有效时仍连续跟手

被放弃的方案

  • 不新增跟手校准 screen，不恢复旧版多动作训练、识别倒计时、强制次数目标或中间结果档
  • 不在 04B 添加 inspector、screen-nav、state-nav、QA 文案或可见调试入口
  • 不把 Input Adapter 设计为按当前目标输出单一预判动作命令

进入下一阶段的条件

  • 已满足：集成 04B 忠实实现两个输入合同、两轮复练、Unknown 跟手和键盘 ↑/↓
  • 已满足：五个 Web 视口均单屏，产品画布无调试脚手架，file:// 有启动保护
  • 后续仅需真实儿童试玩校准动作易懂性与参数，不新增规格门槛

不需要 PM 审查的执行细节

  • 连续 3 帧、700ms freeze、虚拟掌心步长与 CSS 压缩参数
  • 本地模型/WASM 加载、关键点绘制、自动化选择器和测试注入接口
